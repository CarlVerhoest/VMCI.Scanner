## How to use this document

- **It is a process document, not a work order.** It describes the domain Scanner supports so that
  entity names, field semantics and process steps are used correctly. A paragraph here is not a
  ticket: what gets built is decided by the user, step by step.
- **🟡 marks an open question.** An open question is unresolved. When work reaches an area covered
  by one, stop and ask the user; do not proceed on an assumption. All open questions are bundled in
  "Bijlage A — open vragen".
- **It is edited only with the user's permission.** The user and Claude maintain it together.
  Propose a change and wait for a yes — also for recording an answer, fixing an inconsistency or
  closing a 🟡 question.
- Where this document and the code or database disagree, the code and database are the current
  truth. Flag the difference instead of silently changing either side.
- Source documents it refers to live in `docs/Sampledocs/` (see the README there).
